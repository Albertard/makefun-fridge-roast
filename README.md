# Fridge Roast: One Line, Biggest Laugh

A program that writes exactly one line to `/output/entry.txt` — a roast of a smart fridge. Built for the make.fun competition **"Fridge Roast: One Line, Biggest Laugh"** (`u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb`).

## The line

> My smart fridge needed a firmware update, Wi-Fi, and my permission just to make ice - a $40 cooler does it without a password.

The line works because it aims squarely at the fridge itself — its firmware, its Wi-Fi, its ice maker — not a generic gadget gag. The punchline turns on the contrast: a smart appliance needs an update, a connection, and permission to do the one job a $40 cooler does silently, no password required. It is specific to smart fridges, tight at 126 characters with every word earning its place, and it dodges the obvious cracks about the fridge ordering groceries or watching you eat. The absurdity lands on the first read: the "smart" part is the obstacle.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
